# Grimes County document archive

Kept copies of public Grimes County documents followed by the Grimes Growth Watch map
(https://grimesgrowthwatch.com), in case a file is later changed or taken down.

- `court/`  Commissioners Court agendas and minutes since January 2026, from the county's CivicClerk
  meeting portal. Each file is saved as a PDF and as plain text. Names run
  `meeting date_kind_file number_fingerprint`. Text for scanned files was read by machine and can contain errors;
  the PDF is the record.
- `county/` Documents about the SpaceX agreements linked from the county's economic development page.

Nothing here is ever deleted. If the county changes a file, the new version is saved beside the earlier one.
The list of what has been seen, with dates, is `data/document_hashes.json` on the main branch.
Files are added by `scripts/watch_documents.py` in the daily data refresh.
